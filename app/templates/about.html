Federation support

Fedishare includes a minimal ActivityPub/WebFinger implementation so accounts can be discovered from other fediverse services.

  • WebFinger: /.well-known/webfinger?resource=acct:username@your-domain
  • Actor profile: /u/username/actor
  • Outbox: /u/username/outbox
  • Inbox endpoint: /u/username/inbox (MVP logging endpoint)

For production federation, add HTTP Signatures verification, delivery workers, and object dereferencing.
